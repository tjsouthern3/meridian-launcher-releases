# Meridian Launcher — releases

Signed release builds of [Meridian Launcher](https://meridian-launcher.com) for Android,
one per version. The source lives in a private repository; this one exists so people who
sideload the APK can download it here and get automatic updates through Obtainium.

## Get it

- **Google Play** — paid once, updates automatically:
  <https://play.google.com/store/apps/details?id=com.meridian_launcher.pro>
- **Direct APK** — free, the full app: the `meridian-<version>.apk` attached to the
  [latest release](https://github.com/tjsouthern3/meridian-launcher-releases/releases/latest),
  or the same file from [meridian-launcher.com](https://meridian-launcher.com).

## Automatic updates with Obtainium

[Obtainium](https://github.com/ImranR98/Obtainium) is a free, open-source Android app that
installs apps straight from where they are published and keeps them updated.

1. Install Obtainium from [its releases page](https://github.com/ImranR98/Obtainium/releases/latest)
   (it is also on F-Droid through the IzzyOnDroid repository).
2. In Obtainium, tap **Add App** and paste this repository's URL:
   `https://github.com/tjsouthern3/meridian-launcher-releases`
3. Tap **Add**. Obtainium installs the current release, and every version published here
   afterwards shows up in Obtainium as an update.

## Good to know

- APKs here are signed with Meridian's own key. Google Play signs its copies with a
  different key, so an APK from here cannot install over a Play installation, and
  Obtainium cannot update one. To switch, make a backup in Meridian's settings,
  uninstall the Play copy, install from here, and restore.
- Release notes are on each release; Meridian's in-app "What's new" card shows them too.
- Requires Android 8.0 or later.
